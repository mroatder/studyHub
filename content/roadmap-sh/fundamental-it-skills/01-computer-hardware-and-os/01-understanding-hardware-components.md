## วัตถุประสงค์การเรียนรู้

เมื่อจบบทนี้ คุณควรจะ

1. บอกหน้าที่ของ CPU, RAM, Storage, เมนบอร์ด, PSU และ GPU ได้ และอธิบายว่าทำงานร่วมกันอย่างไร
2. อธิบายได้ว่าทำไม RAM ถึงเร็วแต่ข้อมูลหาย ส่วน Storage ช้ากว่าแต่เก็บถาวร
3. เห็นภาพ **ลำดับชั้นของหน่วยความจำ (memory hierarchy)** ว่าทำไมคอมพิวเตอร์ถึงมีที่เก็บข้อมูลหลายระดับ
4. วิเคราะห์ได้ว่าอาการ "เครื่องช้า" หรือ "เครื่องรีบูตเอง" น่าจะมาจากชิ้นส่วนไหน
5. โยงความรู้ฮาร์ดแวร์ไปสู่มุมมองด้านความปลอดภัยได้ เช่น ทำไมต้องเข้ารหัสดิสก์

## สรุปสั้น (TL;DR)

คอมพิวเตอร์ประกอบจากชิ้นส่วนหลัก 6 อย่าง: **CPU** คิดและสั่งงาน, **RAM** เป็นโต๊ะทำงานชั่วคราวที่เร็วแต่ข้อมูลหายเมื่อดับไฟ, **Storage** เก็บถาวรแต่ช้ากว่า, **Motherboard** เชื่อมทุกชิ้นเข้าด้วยกัน, **PSU** แปลงไฟบ้านให้ชิ้นส่วนใช้ได้ และ **GPU** ประมวลผลภาพด้วยแกนจำนวนมาก ทั้งหมดนี้คือพื้นฐานของการหาสาเหตุเครื่องช้า การเลือกซื้ออุปกรณ์ และการป้องกันข้อมูลรั่ว

## เปรียบเทียบกับชีวิตจริง

นึกถึง **ร้านอาหารที่มีครัว**

| ในร้านอาหาร | ในคอมพิวเตอร์ | ข้อสังเกต |
|---|---|---|
| พ่อครัว | **CPU** | ลงมือทำจริง ยิ่งพ่อครัวเก่งและมีหลายคน งานยิ่งเสร็จเร็ว |
| โต๊ะเตรียมของข้างเตา | **RAM** | หยิบง่ายมาก แต่โต๊ะมีที่จำกัด และเลิกงานแล้วต้องเก็บกวาดทิ้ง |
| ห้องเก็บของ / ตู้เย็น | **Storage** | จุได้เยอะและของไม่หาย แต่ต้องเดินไปหยิบ |
| ทางเดินและระบบสื่อสารในร้าน | **Motherboard** | ถ้าทางเดินแคบ พ่อครัวเก่งแค่ไหนก็ช้า |
| ไฟฟ้าและแก๊ส | **PSU** | ถ้าไฟตกหรือกระชาก ครัวหยุดทำงานหรืออุปกรณ์เสีย |
| ทีมตกแต่งจานจำนวนมาก | **GPU** | แต่ละคนทำงานง่ายๆ แต่ทำพร้อมกันได้ทีละร้อยจาน |

เปรียบเทียบนี้จะกลับมาอธิบายปัญหาได้หลายอย่าง เช่น โต๊ะเล็กเกินไป (RAM ไม่พอ) พ่อครัวต้องวิ่งไปห้องเก็บของบ่อยจนร้านช้า

## 1. ตัวประมวลผล (CPU)

### 1.1 CPU ทำอะไรกันแน่

CPU (Central Processing Unit) เรียกว่าสมองของคอมพิวเตอร์ แต่จริงๆ แล้วมัน "ไม่ฉลาด" เลย สิ่งที่ CPU ทำได้คือคำสั่งพื้นฐานเล็กๆ เช่น บวกเลข เปรียบเทียบเลข ย้ายข้อมูล แต่ทำได้เร็วระดับพันล้านครั้งต่อวินาที โปรแกรมทั้งหมดที่เราใช้ ตั้งแต่เบราว์เซอร์จนถึงเกม ก็คือการต่อคำสั่งง่ายๆ เหล่านี้เป็นลำดับยาวๆ

ภายใน CPU มีส่วนสำคัญ 3 อย่างที่ควรรู้จัก

- **หน่วยควบคุม (Control Unit):** อ่านคำสั่งแล้วสั่งส่วนอื่นให้ทำตาม
- **หน่วยคำนวณ (ALU: Arithmetic Logic Unit):** ทำคณิตศาสตร์และตรรกะ
- **รีจิสเตอร์ (Register):** ที่พักข้อมูลที่เล็กและเร็วที่สุดในเครื่อง อยู่ในตัว CPU เก็บค่าที่กำลังคำนวณอยู่ตอนนั้น

### 1.2 วงจรการทำงาน: Fetch → Decode → Execute

CPU ทำงานเป็นวงจรเดิมซ้ำไปเรื่อยๆ ตราบที่เครื่องเปิดอยู่

ลองดูโปรแกรมเล็กๆ ที่บวก 2 + 3 แล้วเก็บผล กดเล่นหรือกดถัดไปทีละขั้น สังเกตว่าข้อมูลและคำสั่งวิ่งระหว่าง RAM กับส่วนต่างๆ ใน CPU อย่างไร

::cpu-cycle
::

> **หมายเหตุสำหรับผู้อ่านอยากลึก:** CPU สมัยใหม่ไม่ได้ทำทีละคำสั่งแบบตรงๆ แต่ใช้เทคนิคเช่น **pipeline** (เริ่มดึงคำสั่งถัดไปก่อนคำสั่งก่อนหน้าจะเสร็จ เหมือนสายพานโรงงาน) ทำให้ทำได้หลายคำสั่งซ้อนกัน แต่หลักการ fetch-decode-execute ยังเป็นพื้นฐานเหมือนเดิม

### 1.3 แกนประมวลผล (Core) หลายแกน

CPU ยุคใหม่มีหลาย **แกน (core)** แต่ละแกนเป็นหน่วยประมวลผลอิสระ ทำตามชุดคำสั่ง (instruction stream) ของตัวเองได้พร้อมกัน

- 1 แกนทำได้ทีละงาน (โดยประมาณ) CPU 8 แกนจึงรัน 8 งานพร้อมกันจริงๆ
- **แต่ไม่ใช่ว่ามีแกนมากแล้วทุกโปรแกรมเร็วขึ้นตามสัดส่วน** โปรแกรมต้องถูกเขียนให้แบ่งงานเป็นหลายส่วนได้ ถ้าโปรแกรมเป็นขั้นตอนเรียงลำดับที่ขั้นหลังต้องรอขั้นก่อน แกนที่เหลือก็ว่างเปล่า
- ตัวอย่าง: ตัดต่อวิดีโอหรือคอมไพล์โค้ดแบ่งงานได้ดีจึงได้ประโยชน์จากหลายแกน ส่วนโปรแกรมเก่าที่ใช้แกนเดียว แกนที่เหลือไม่ช่วยอะไร

### 1.4 ความเร็วสัญญาณนาฬิกา (Clock Speed)

Clock speed วัดเป็น **เฮิรตซ์ (Hz)** ปัจจุบันเป็น **GHz** (พันล้านรอบต่อวินาที) บอกว่าแต่ละแกนเดินวงจรได้กี่รอบต่อวินาที

**ข้อควรระวัง:** ตัวเลข GHz ที่สูงกว่าไม่ได้แปลว่าเร็วกว่าเสมอไป เพราะสิ่งที่ตัดสินจริงๆ คือ **จำนวนงานที่ทำเสร็จต่อรอบ** ซึ่งขึ้นกับสถาปัตยกรรม (architecture) ของ CPU CPU รุ่นใหม่ clock ต่ำกว่ารุ่นเก่าก็อาจเร็วกว่าได้ เพราะทำงานได้มากกว่าต่อรอบ

### 1.5 แคช (Cache): หน่วยความจำจิ๋วที่ติดกับ CPU

ปัญหาคือ CPU เร็วมาก แต่ RAM ตามไม่ทัน ถ้าทุกครั้งที่ CPU ต้องการข้อมูลแล้วไปรอจาก RAM CPU จะว่างเปล่าเสียเวลาไปมาก วิธีแก้คือใส่หน่วยความจำเล็กๆ ที่เร็วสุดๆ ไว้ติด CPU เรียกว่า **แคช (cache)** เพื่อเก็บข้อมูลที่ใช้บ่อย

แคชมีหลายระดับ

| ระดับ | ขนาดโดยประมาณ | ความเร็ว | หมายเหตุ |
|---|---|---|---|
| **L1** | หลักสิบ KB ต่อแกน | เร็วที่สุด | อยู่ในแต่ละแกนโดยตรง |
| **L2** | หลักร้อย KB ถึงไม่กี่ MB | เร็วมาก | มักเป็นของแต่ละแกน |
| **L3** | หลาย MB ถึงหลายสิบ MB | เร็ว | มักใช้ร่วมกันทุกแกน |

อธิบายด้วยครัว: L1 เหมือนของที่พ่อครัวถืออยู่ในมือ L2 คือของบนเขียงตรงหน้า L3 คือชั้นวางของข้างเตา และ RAM คือโต๊ะเตรียมของ

**ทำไมแคชได้ผล:** โปรแกรมส่วนใหญ่มักใช้ข้อมูลเดิมซ้ำๆ (เช่น ลูป) หรือใช้ข้อมูลที่อยู่ใกล้ๆ กัน จึงโหลดมาไว้ใกล้ CPU ครั้งเดียวแล้วใช้ได้หลายรอบ (เรียกหลักการนี้ว่า locality)

## 2. ลำดับชั้นของหน่วยความจำ (Memory Hierarchy)

ก่อนเข้า RAM และ Storage ควรเห็นภาพรวมก่อน เพราะนี่คือแนวคิดที่ช่วยให้เข้าใจทั้งบทนี้ ปัญหาพื้นฐานคือ **ไม่มีหน่วยความจำชนิดไหนที่เร็ว ใหญ่ และถูก ได้พร้อมกัน** ยิ่งเร็วยิ่งแพงต่อ GB และยิ่งจุได้น้อย คอมพิวเตอร์จึงใช้หลายระดับซ้อนกัน

ลองเทียบความเร็วให้เห็นภาพ กดปุ่มเพื่อสลับมุมมอง

> ตัวเลขความเร็วข้างบนเป็นค่าโดยประมาณเพื่อให้เห็นลำดับขนาด ค่าจริงต่างกันไปตามรุ่นฮาร์ดแวร์

ข้อสรุปที่ควรจำ: **ยิ่งใกล้ CPU ยิ่งเร็ว ยิ่งเล็ก ยิ่งแพง** ระบบจะพยายามเก็บข้อมูลที่ใช้บ่อยไว้ชั้นบน และดันข้อมูลที่ไม่ค่อยใช้ลงชั้นล่าง

## 3. หน่วยความจำหลัก (RAM)

### 3.1 RAM คืออะไร

RAM (Random Access Memory) คือพื้นที่ทำงานชั่วคราวของระบบปฏิบัติการและแอปที่กำลังเปิดอยู่ ชื่อ "Random Access" หมายถึงเข้าถึงข้อมูลตำแหน่งไหนก็ได้ด้วยเวลาใกล้เคียงกัน ไม่ต้องไล่อ่านตามลำดับ

### 3.2 ธรรมชาติแบบ Volatile

RAM เป็นหน่วยความจำแบบ **volatile (ระเหยง่าย)** หมายความว่า **ต้องมีไฟเลี้ยงตลอดเวลา** ทันทีที่ปิดเครื่อง ข้อมูลใน RAM จะเลือนหายไป นี่คือเหตุผลที่ไฟล์ที่ยังไม่ได้บันทึกหายเมื่อไฟดับ

เหตุผลเชิงเทคนิคอย่างง่าย: RAM ทั่วไป (DRAM) เก็บบิตด้วยประจุไฟฟ้าจิ๋วๆ ซึ่งรั่วหายเอง จึงต้อง "รีเฟรช" ซ้ำตลอดเวลา เมื่อไม่มีไฟ ก็ไม่มีใครรีเฟรช ข้อมูลก็หาย

### 3.3 ตัวชี้วัดของ RAM

- **ความจุ (capacity):** วัดเป็น GB เช่น 16GB, 32GB บอกว่ารองรับงานพร้อมกันได้มากแค่ไหน
- **ความเร็ว (speed):** วัดเป็น MT/s (megatransfers ต่อวินาที) เช่น **DDR5-5600** หมายถึงรุ่น DDR5 ที่ส่งข้อมูลได้ราว 5,600 ล้านครั้งต่อวินาที รุ่นใหม่ (DDR5) เร็วกว่ารุ่นเก่า (DDR4)
- RAM คุยกับ CPU ผ่าน **ช่องความเร็วสูง (memory channels)** บนเมนบอร์ด

### 3.4 เมื่อ RAM ไม่พอ: Swap และ Thrashing

ถ้า RAM เต็ม ระบบปฏิบัติการมีทางออกคือ **ย้ายหน้าความจำ (memory page) ที่ไม่ได้ใช้ไปพักบน Storage** (เรียกว่า swap หรือ paging file บน Windows) เพื่อเอาที่ว่างให้งานอื่น

ปัญหาคือ Storage ช้ากว่า RAM มาก ถ้าระบบต้องสลับข้อมูลไปมาถี่ๆ จนเกือบไม่มีเวลาทำงานจริง เครื่องจะอืดสุดๆ อาการนี้เรียกว่า **thrashing**

ลองเล่นเอง: เปิดโปรแกรมให้ RAM เต็ม แล้วดูว่าระบบทำอะไรและเครื่องรู้สึกอย่างไร

::ram-swap
::

**วิธีสังเกตในงานจริง:** เครื่องช้า ไฟดิสก์กระพริบถี่ และ Task Manager แสดงการใช้ RAM ใกล้ 100% เป็นสัญญาณของ RAM ไม่พอ

## 4. ที่เก็บข้อมูลถาวร (Storage): HDD และ SSD

Storage เก็บข้อมูลได้ **โดยไม่ต้องมีไฟเลี้ยง** (non-volatile) ข้อมูลอยู่ครบแม้ปิดเครื่อง ปัจจุบันวงการเปลี่ยนจาก HDD เป็น SSD เป็นหลัก แต่ทั้งสองทำหน้าที่เดียวกัน

::compare-cards{:items='[{"title":"HDD","subtitle":"Hard Disk Drive (จานหมุน)","points":["เป็นอุปกรณ์เชิงกล: จานแม่เหล็กหมุน และแขนอ่าน/เขียนที่เลื่อนไปหาข้อมูล","ต้องรอจานหมุนและแขนเลื่อน จึงมีเวลาหาข้อมูล (seek time) สูง โดยเฉพาะเมื่อข้อมูลกระจัดกระจาย","กลัวแรงกระแทก เพราะมีชิ้นส่วนเคลื่อนไหว","ราคาต่อความจุถูก เหมาะเก็บไฟล์ขนาดใหญ่หรือสำรองข้อมูล"]},{"title":"SSD","subtitle":"Solid State Drive (ชิปแฟลช)","points":["ใช้ชิปหน่วยความจำแฟลช (NAND) ไม่มีชิ้นส่วนเคลื่อนไหว","อ่าน/เขียนแบบสุ่มได้เกือบทันที เพราะไม่ต้องรอกลไก","ทนแรงกระแทกและเงียบ","แบบ NVMe ต่อผ่าน PCIe โดยตรง เร็วเกิน 7,000 MB/s"]}]'}
::

ลองกดอ่านข้อมูลสุ่มดูว่า HDD กับ SSD ทำงานต่างกันอย่างไรจากข้างใน

::drive-internals
::

### 4.1 SSD เก็บข้อมูลอย่างไร

ภายใน SSD เป็นเซลล์ทรานซิสเตอร์ที่ **กักอิเล็กตรอนไว้** (แบบ floating-gate หรือ charge-trap) ปริมาณประจุที่กักไว้แทนค่าเลขฐานสอง 0 และ 1 เพราะประจุถูกกักไว้ได้โดยไม่ต้องมีไฟ ข้อมูลจึงอยู่ถาวร

ข้อควรรู้เพิ่ม: เซลล์แฟลชเขียนทับได้จำนวนครั้งจำกัด (มีอายุการเขียน) SSD จึงมีตัวควบคุมที่กระจายการเขียนไปทั่วชิป (wear leveling) เพื่อยืดอายุ

### 4.2 ทำไม NVMe เร็วกว่ามาก

SSD ยุคแรกต่อผ่านพอร์ต SATA ซึ่งออกแบบมาสำหรับ HDD ทำให้เป็นคอขวด **NVMe (Non-Volatile Memory Express)** เป็นมาตรฐานที่ออกแบบมาสำหรับแฟลชโดยเฉพาะ และต่อ **ตรงเข้าบัส PCIe** ซึ่งเป็นช่องทางความเร็วสูงของระบบ จึงเลี่ยงคอขวดเดิมและทำความเร็วได้เกิน 7,000 MB/s ในรุ่นที่เร็ว

### 4.3 HDD vs SSD เลือกอย่างไร

- ติดตั้งระบบปฏิบัติการและโปรแกรมที่ใช้บ่อย: **SSD** (เปิดเครื่องและโปรแกรมเร็วขึ้นชัดเจน)
- เก็บข้อมูลมหาศาลราคาประหยัด เช่น คลังวิดีโอหรือไฟล์สำรอง: **HDD**
- เครื่องพกพาที่อาจถูกกระแทก: **SSD**

## 5. เมนบอร์ดและชิปเซ็ต (Motherboard & Chipset)

### 5.1 เมนบอร์ดคืออะไร

เมนบอร์ด (Motherboard) คือ **แผงวงจรพิมพ์ (PCB: Printed Circuit Board)** ขนาดใหญ่ที่ยึดทุกชิ้นส่วนไว้ และเชื่อมกันทางไฟฟ้า บนเมนบอร์ดจะมี

- **ช่องใส่ CPU (CPU socket)**
- **ช่องใส่ RAM (DIMM slots)**
- **ช่องต่อการ์ดเพิ่ม (PCIe slots)** สำหรับการ์ดจอและ SSD NVMe
- **ช่องต่อ Storage** และพอร์ตภายนอก เช่น USB, เสียง, เครือข่าย
- **ชิปเซ็ต (Chipset)** และชิปเฟิร์มแวร์ (BIOS/UEFI) ที่ช่วยให้เครื่องเริ่มทำงานได้

กดแต่ละชิ้นส่วนบนแผนผังเพื่อดูว่าคืออะไรและทำหน้าที่อะไร

::motherboard-diagram
::

### 5.2 เส้นทางข้อมูล (Traces)

เส้นทองแดงจิ๋วที่ฝังอยู่ในชั้นของแผงวงจรเรียกว่า **traces** ทำหน้าที่เป็น "ถนนของข้อมูล" ที่นำสัญญาณไฟฟ้าระหว่างชิ้นส่วนต่างๆ การออกแบบเส้นเหล่านี้ให้สั้นและสะอาดมีผลต่อความเร็วและความเสถียร

### 5.3 ชิปเซ็ต (Chipset)

ชิปเซ็ตคือชิปควบคุมที่ทำหน้าที่เป็น **ศูนย์จัดการจราจรข้อมูล** ระหว่าง CPU, หน่วยความจำ และอุปกรณ์ต่อพ่วง ชิปเซ็ตเป็นตัวกำหนดขีดความสามารถของเมนบอร์ด เช่น

- พอร์ต USB ที่ทำความเร็วสูงสุดได้กี่พอร์ต
- รองรับการปรับแต่งความเร็ว CPU เกินค่าปกติ (**overclock**) หรือไม่
- มีเลน PCIe ให้ใช้เท่าไร ซึ่งกำหนดว่าติดการ์ดและ SSD ได้กี่ชิ้นที่ความเร็วเต็ม

**ข้อควรรู้ตอนซื้อเครื่อง:** CPU ต้องเข้ากับ socket และชิปเซ็ตของเมนบอร์ด ซื้อแยกแล้วไม่เข้ากันก็ใช้ไม่ได้

## 6. ชุดจ่ายไฟ (PSU: Power Supply Unit)

### 6.1 หน้าที่

ไฟจากปลั๊กบ้านเป็น **กระแสสลับแรงดันสูง (AC)** แต่ชิ้นส่วนในคอมพิวเตอร์ต้องการ **กระแสตรงแรงดันต่ำที่นิ่งมาก (DC)** PSU แปลงให้ และแบ่งออกเป็นสายไฟ (rail) หลายระดับแรงดัน ได้แก่ **+12V, +5V และ +3.3V**

::psu-flow
::

### 6.2 ประสิทธิภาพ และป้าย 80 Plus

ระหว่างแปลงไฟ PSU สูญเสียพลังงานบางส่วนเป็นความร้อน มาตรฐาน **80 Plus** รับรองว่า PSU มีประสิทธิภาพอย่างน้อยเท่าไรที่โหลดต่างๆ เรียงจากต่ำไปสูงได้แก่ **Bronze, Silver, Gold, Platinum และ Titanium** ยิ่งระดับสูง ยิ่งเสียพลังงานเป็นความร้อนน้อย ประหยัดไฟและเย็นกว่า

### 6.3 PSU คุณภาพต่ำอันตรายอย่างไร

PSU ที่กำลังไม่พอหรือคุมแรงดันไม่ดีทำให้เกิด **ระบบไม่เสถียร, รีบูตเอง, และอาจทำให้ฮาร์ดแวร์เสียหายถาวร** เพราะแรงดันไฟกระเพื่อม (**voltage ripple**) เป็นเหตุผลที่ไม่ควรประหยัดกับ PSU

เมื่อเลือก PSU ให้ดูที่: กำลังไฟรวม (วัตต์) ต้องพอสำหรับการ์ดจอและ CPU รวมกันพร้อมเผื่อ, ป้าย 80 Plus และยี่ห้อที่เชื่อถือได้

## 7. หน่วยประมวลผลกราฟิก (GPU)

### 7.1 GPU กับ CPU ต่างกันอย่างไร

GPU ถูกออกแบบมาเพื่อ **สร้างภาพขึ้นจอให้เร็วที่สุด** โดยจัดการหน่วยความจำเพื่อเร่งการสร้างภาพ

ลองแข่งวาดภาพ 128 พิกเซลระหว่าง CPU กับ GPU

::cpu-vs-gpu
::

สรุปความต่าง: **CPU** แกนน้อย แต่ละแกนแรงและฉลาด เหมาะกับงานตรรกะซับซ้อนที่ต้องทำเป็นลำดับ ส่วน **GPU** แกนเล็กๆ จำนวนหลายพันแกน เหมาะกับงานที่ทำซ้ำแบบเดียวกันกับข้อมูลจำนวนมาก

อุปมา: งานวาดภาพ 1 ล้านพิกเซล ถ้าใช้ศาสตราจารย์ 8 คน (CPU) ทำทีละพิกเซลก็ช้า แต่ถ้าใช้นักเรียน 5,000 คน (GPU) แต่ละคนทาสีพิกเซลของตัวเองพร้อมกัน จะเสร็จเร็วกว่ามาก เพราะงานนี้ไม่ต้องใช้ความฉลาดสูง

### 7.2 GPU แบบฝังกับแบบแยก

- **GPU แบบฝัง (integrated):** อยู่ในตัว CPU หรือบนเมนบอร์ด **ใช้ RAM ร่วมกับระบบ** ประหยัดไฟและราคา เหมาะกับงานทั่วไป
- **GPU แบบแยก (dedicated):** เป็นการ์ดเสียบแยก มี **หน่วยความจำของตัวเองเรียกว่า VRAM** ความเร็วสูง เหมาะกับเกม งานกราฟิกและงานหนัก

### 7.3 GPU ใช้ทำอะไรได้นอกจากภาพ

ความสามารถในการทำงานขนานทำให้ GPU ถูกใช้ในงานที่ไม่ใช่กราฟิกด้วย เช่น **การเทรน machine learning**, **การเข้ารหัส (cryptography)** และ **การแปลงไฟล์วิดีโอ (video transcoding)**

## มุมมองด้าน Security

ผู้เรียนสาย Cyber Security ควรรู้ว่าความรู้ฮาร์ดแวร์เชื่อมกับความปลอดภัยอย่างไร

- **ข้อมูลใน RAM หายเมื่อดับเครื่อง แต่ไม่ได้หายทันที:** เหตุการณ์ละเมิดความปลอดภัยหลายครั้งทิ้งหลักฐานไว้ใน RAM เท่านั้น (เช่น มัลแวร์ที่ไม่เขียนไฟล์ลงดิสก์ หรือคีย์เข้ารหัสที่กำลังใช้งาน) ผู้ตรวจสอบเหตุการณ์ (digital forensics) จึงมักเก็บภาพ RAM ก่อนปิดเครื่องที่ต้องสงสัย เรียกว่า memory acquisition
- **ข้อมูลบน Storage ต้องเข้ารหัส:** เครื่องหรือดิสก์ที่หายถูกถอดไปอ่านที่อื่นได้ จึงนิยมใช้ **การเข้ารหัสทั้งดิสก์ (full-disk encryption)** เช่น BitLocker ของ Windows
- **การลบไฟล์ไม่ได้แปลว่าข้อมูลหายจริง:** ข้อมูลที่ลบบน HDD มักยังอยู่จนกว่าจะถูกเขียนทับ และบน SSD การลบข้อมูลให้หมดจริงมีความซับซ้อนกว่าเดิม จึงควรใช้เครื่องมือลบข้อมูลที่ออกแบบมาโดยเฉพาะ หรือการเข้ารหัสทั้งดิสก์ก่อน
- **ฮาร์ดแวร์ก็เป็นเป้าโจมตี:** เฟิร์มแวร์ (BIOS/UEFI) บนเมนบอร์ดทำงานก่อนระบบปฏิบัติการ ถ้าถูกแก้ไข มัลแวร์จะอยู่รอดแม้ติดตั้ง Windows ใหม่
- **GPU กับรหัสผ่าน:** ความสามารถทำงานขนานของ GPU ถูกใช้เดารหัสผ่านแบบ brute force ได้เร็วมาก จึงควรตั้งรหัสผ่านให้ยาวและคาดเดายาก

| HDD (Hard Disk Drive) | ฮาร์ดดิสก์ | ที่เก็บข้อมูลแบบจานหมุน |
| SSD (Solid State Drive) | เอสเอสดี | ที่เก็บข้อมูลแบบแฟลช ไม่มีชิ้นส่วนเคลื่อนไหว |
| NAND flash | แนนด์แฟลช | ชนิดชิปความจำที่ใช้ใน SSD |
| NVMe | เอ็นวีเอ็มอี | มาตรฐาน SSD ที่ต่อ PCIe ตรง เร็วมาก |
| Motherboard | เมนบอร์ด | แผงวงจรหลักเชื่อมทุกชิ้นส่วน |
| PCB (Printed Circuit Board) | แผงวงจรพิมพ์ | แผ่นที่มีเส้นทองแดงเชื่อมวงจร |
| Chipset | ชิปเซ็ต | ชิปจัดการจราจรข้อมูลบนเมนบอร์ด |
| PCIe | พีซีไอ-อี | บัสความเร็วสูงสำหรับการ์ดเพิ่มและ SSD |
| PSU (Power Supply Unit) | ชุดจ่ายไฟ | แปลงไฟ AC เป็น DC ให้ชิ้นส่วน |
| 80 Plus | เอตตี้พลัส | มาตรฐานรับรองประสิทธิภาพของ PSU |
| Voltage ripple | แรงดันกระเพื่อม | ความไม่นิ่งของแรงดันที่ทำให้ฮาร์ดแวร์เสียหาย |
| GPU (Graphics Processing Unit) | จีพียู / การ์ดจอ | ชิปประมวลผลภาพ แกนเยอะ ทำงานขนาน |
| VRAM | วีแรม | หน่วยความจำของ GPU แยก |
| Full-disk encryption | การเข้ารหัสทั้งดิสก์ | เข้ารหัสทุกอย่างบนดิสก์ กันข้อมูลรั่วเมื่ออุปกรณ์หาย |

## ตรวจความเข้าใจ

คิดคำตอบในใจก่อน แล้วกดดูเฉลย

::reveal{question="ความต่างหลักระหว่าง RAM (volatile) กับ Storage (non-volatile) คืออะไร"}
RAM ต้องมีไฟเลี้ยงตลอดจึงเก็บข้อมูลได้ ดับไฟแล้วข้อมูลหายทั้งหมด แต่ RAM เร็วมาก จึงใช้เป็นโต๊ะทำงานชั่วคราว ส่วน Storage เก็บข้อมูลได้ถาวรโดยไม่ต้องมีไฟ แต่ช้ากว่า จึงใช้เก็บไฟล์และโปรแกรมระยะยาว
::

::reveal{question="จำนวนแกน (core) และ clock speed ส่งผลต่อประสิทธิภาพของ CPU อย่างไร"}
Clock speed บอกว่าแต่ละแกนทำงานได้กี่รอบต่อวินาที ส่วนจำนวนแกนบอกว่าทำงานแยกกันพร้อมกันได้กี่งาน แกนมากช่วยเมื่อโปรแกรมแบ่งงานขนานได้ ส่วน clock speed ช่วยให้แต่ละงานเสร็จเร็วขึ้น แต่ตัวเลข GHz อย่างเดียวไม่ตัดสินความเร็ว เพราะสถาปัตยกรรมที่ทำงานได้มากต่อรอบสำคัญกว่า
::

::reveal{question="ทำไม NVMe SSD ถึงเร็วกว่า HDD แบบกลไกมาก"}
เพราะ SSD ไม่มีชิ้นส่วนเคลื่อนไหว ใช้ชิปแฟลช (NAND) จึงอ่านเขียนแบบสุ่มได้เกือบทันที ไม่ต้องรอจานหมุนและแขนเลื่อนแบบ HDD นอกจากนี้ NVMe ต่อตรงผ่านบัส PCIe ซึ่งเลี่ยงคอขวดของอินเทอร์เฟซรุ่นเก่า จึงเร็วเกิน 7,000 MB/s
::

::reveal{question="ชิปเซ็ตบนเมนบอร์ดมีบทบาทอะไรในการสื่อสารของระบบ"}
ชิปเซ็ตเป็นศูนย์จัดการจราจรข้อมูลระหว่าง CPU, หน่วยความจำ และอุปกรณ์ต่อพ่วง และเป็นตัวกำหนดความสามารถของเมนบอร์ด เช่น จำนวนพอร์ต USB ที่ทำความเร็วสูงสุดได้ การรองรับ overclock และจำนวนเลน PCIe
::

::reveal{question="เปิดหลายแท็บแล้วเครื่องอืด ดิสก์กระพริบถี่ มักเกิดจากอะไร และเกี่ยวกับ thrashing อย่างไร"}
น่าจะเป็น RAM ไม่พอ ระบบจึงย้ายข้อมูลที่ไม่ใช้ลงดิสก์ (swap) เพื่อเอาที่ว่าง แต่เมื่อต้องใช้ข้อมูลนั้นอีกก็ต้องโหลดกลับและย้ายอย่างอื่นออก วนซ้ำถี่จนเครื่องอืด ซึ่งเรียกว่า thrashing วิธีแก้คือเพิ่ม RAM หรือปิดโปรแกรมที่ไม่จำเป็น
::

::reveal{question="ทำไมผู้ตรวจสอบเหตุการณ์ด้านความปลอดภัยจึงมักเก็บข้อมูลใน RAM ก่อนปิดเครื่องที่ต้องสงสัย"}
เพราะข้อมูลใน RAM หายเมื่อดับเครื่อง และอาจมีหลักฐานที่ไม่อยู่บนดิสก์เลย เช่น มัลแวร์ที่รันในหน่วยความจำอย่างเดียว หรือรายการโปรเซสและการเชื่อมต่อเครือข่ายขณะนั้น ถ้าปิดเครื่องก่อนจะสูญเสียหลักฐานเหล่านี้
::

## สรุป

- ชิ้นส่วนทั้ง 6 ทำงานเป็นทีม: CPU ประมวลผล, RAM พักข้อมูลที่ใช้อยู่, Storage เก็บถาวร, เมนบอร์ดเชื่อมทุกอย่าง, PSU จ่ายไฟนิ่ง, GPU ช่วยงานภาพและงานขนาน
- แนวคิดหลักที่ต้องจำคือ **ลำดับชั้นหน่วยความจำ**: ยิ่งใกล้ CPU ยิ่งเร็ว เล็ก และแพง
- ความรู้นี้ใช้วิเคราะห์ปัญหาเครื่องช้าและเลือกอุปกรณ์ได้ และเป็นฐานของงาน Security เช่น forensics และการเข้ารหัสดิสก์
- บทถัดไปจะเรียนเรื่องการเชื่อมต่อชิ้นส่วนเหล่านี้กับอุปกรณ์ภายนอกและเครือข่ายด้วยมาตรฐานสาย/พอร์ตต่างๆ
