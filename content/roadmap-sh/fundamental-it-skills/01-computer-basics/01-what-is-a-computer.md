## สรุปสั้น (TL;DR)

คอมพิวเตอร์คือเครื่องที่ทำงาน 3 อย่างวนซ้ำ: **รับข้อมูลเข้า (Input)** → **ประมวลผล (Process)** → **ส่งผลออก (Output)** ไม่ว่าจะเป็นมือถือ แล็ปท็อป หรือเซิร์ฟเวอร์ ล้วนทำตามหลักนี้

## เปรียบเทียบกับชีวิตจริง

เหมือน **เครื่องชงกาแฟอัตโนมัติ** เรากดปุ่มเลือกเมนู (input) เครื่องคำนวณปริมาณและชง (process) แล้วได้กาแฟออกมา (output)

## ศัพท์สำคัญ

| English | คำไทย | ความหมายสั้นๆ |
|---|---|---|
| Input | ข้อมูลเข้า | สิ่งที่เราป้อนให้เครื่อง |
| Output | ผลลัพธ์ | สิ่งที่เครื่องส่งกลับมา |
| Program | โปรแกรม | ชุดคำสั่งที่บอกเครื่องว่าต้องทำอะไร |

## เอาไปใช้จริง

เวลาวิเคราะห์ปัญหาระบบ ให้ถามเป็นลำดับว่า ข้อมูลเข้าถูกไหม ประมวลผลผิดตรงไหน และผลลัพธ์ออกมาตามที่คาดไหม วิธีคิดแบบนี้ใช้ได้ทั้งงาน IT Support และ Security
