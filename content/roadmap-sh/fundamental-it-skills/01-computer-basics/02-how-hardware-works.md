> **บทตัวอย่าง** สร้างขึ้นเพื่อทดสอบเทมเพลตและ component แอนิเมชัน เนื้อหาเรียบเรียงเอง ไม่ได้คัดลอกจากต้นฉบับ

## สรุปสั้น (TL;DR)

คอมพิวเตอร์ทุกเครื่องมีชิ้นส่วนหลักที่ผลัดกันทำงาน คือ **ตัวประมวลผล (CPU)** คิดเลขและสั่งงาน, **หน่วยความจำ (RAM)** เก็บของที่กำลังใช้อยู่ และ **ที่เก็บข้อมูล (Storage)** เก็บของถาวร รู้เรื่องนี้แล้วจะเข้าใจว่าทำไมเครื่องช้า และทำไมไฟล์ที่ยังไม่เซฟถึงหายเมื่อไฟดับ

## เปรียบเทียบกับชีวิตจริง

ลองนึกถึง **ครัวร้านอาหาร**

- **CPU** คือ พ่อครัว ลงมือทำอาหารจริง
- **RAM** คือ โต๊ะเตรียมของข้างเตา วางวัตถุดิบที่กำลังใช้ หยิบง่ายแต่โต๊ะมีที่จำกัด
- **Storage** คือ ห้องเก็บของ จุของได้มากแต่ต้องเดินไปหยิบ ช้ากว่า

ถ้าโต๊ะเล็กเกินไป พ่อครัวต้องวิ่งไปห้องเก็บของบ่อยๆ ร้านก็ช้าลง เหมือนเครื่องที่ RAM ไม่พอ

## ศัพท์สำคัญ

| English | คำอ่าน / คำไทย | ความหมายสั้นๆ |
|---|---|---|
| CPU (Central Processing Unit) | ซีพียู / ตัวประมวลผลกลาง | สมองที่คิดและสั่งงาน |
| RAM (Random Access Memory) | แรม / หน่วยความจำ | ที่พักข้อมูลชั่วคราวที่เร็วมาก |
| Storage | สตอเรจ / ที่เก็บข้อมูล | เก็บไฟล์ถาวร (SSD, HDD) |
| Motherboard | เมนบอร์ด / แผงวงจรหลัก | แผงที่เชื่อมทุกชิ้นส่วนเข้าด้วยกัน |
| GPU (Graphics Processing Unit) | จีพียู / การ์ดจอ | ชิปประมวลผลภาพโดยเฉพาะ |
| Core | คอร์ / แกนประมวลผล | หน่วยทำงานย่อยใน CPU |

## เอาไปใช้จริง

- **ซื้อหรืออัปเกรดเครื่อง:** เครื่องอืดเวลาเปิดหลายแท็บ มักแก้ได้ด้วยการเพิ่ม RAM ส่วนเครื่องบูตช้า การเปลี่ยน HDD เป็น SSD ช่วยได้มาก
- **งาน IT Support:** ตรวจอาการ "ช้า" ได้ว่าคอขวดอยู่ที่ CPU, RAM หรือ Storage ดูจาก Task Manager
- **งาน Security:** ข้อมูลใน RAM หายเมื่อดับเครื่อง ผู้ตรวจสอบเหตุการณ์ (forensics) จึงต้องเก็บข้อมูลใน RAM ก่อนปิดเครื่องที่ต้องสงสัย ส่วนข้อมูลใน Storage ต้องเข้ารหัสไว้เผื่อเครื่องหาย
